三项成功验收请求的模型用量共 2,065 token；具体回答、引用标题及各次用量已保存到 `data/v1/integration_report.json`。此前的 HTTP 402 余额阻塞已解决。再次运行完整验收：

```powershell
$ragPython = 'D:\Anaconda\envs\edu-rag\python.exe'
& $ragPython -X utf8 scripts/verify_v1.py --with-llm --check-idempotence
```

该命令会发起三次计费模型请求，同时检查知识目录、知识点过滤、空课程跳过模型、重复导入与检索基线。真实模型验收结果与单元测试的模拟响应分开记录。

## 当前边界

当前数据是原创功能样例，未覆盖某教材的完整三年级课程。V1 使用精确向量检索与提示词约束，尚未实现 BM25/RRF、重排、正式门控、用户登录或公网部署。引用编号校验只能验证来源存在，不能证明所有答案内容都正确。
