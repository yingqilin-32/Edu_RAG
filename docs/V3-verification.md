- 同一只读、可重复读快照内评测；结束后重新读取数据库指纹，正文、向量、元数据和答案未发生变化。

## 检索效果

39 道开发问题中，31 道按课程内知识点判断相关，8 道要求命中指定题号。标签在首次运行前固定，全部纳入统计；不因结果好坏删除样例。Hit@5 是前五名中是否包含正确目标；MRR@5 是首个正确目标排名倒数的平均值，五名外记 0。两种标签粒度分别报告，合计值只反映本次人为设定的题型比例。

| 全部 39 道 | Hit@1 | Hit@5 | MRR@5 | search() 耗时中位数 |
| --- | ---: | ---: | ---: | ---: |
| Dense | 82.05% | 87.18% | 0.8419 | 443 ms |
| BM25 | 89.74% | 100% | 0.9487 | 104 ms |
| Dense + BM25 + RRF | 87.18% | 100% | 0.9209 | 474 ms |

| 31 道自然问题 | Hit@1 | Hit@5 | MRR@5 |
| --- | ---: | ---: | ---: |
| Dense | 96.77% | 100% | 0.9839 |
| BM25 | 100% | 100% | 1.0000 |
| Dense + BM25 + RRF | 96.77% | 100% | 0.9839 |

| 8 道题号查询 | Hit@1 | Hit@5 | MRR@5 |
| --- | ---: | ---: | ---: |
| Dense | 25% | 37.5% | 0.2917 |
| BM25 | 50% | 100% | 0.7500 |
| Dense + BM25 + RRF | 50% | 100% | 0.6771 |

相较 Dense，混合模式首个正确目标的排名改善 6 道、相同 33 道、退步 0 道。其中 5 道从前五名外进入前五名；改善全部来自题号组。31 道自然问题没有新增 Hit@5 收益。BM25 单路在本次开发集的总体 MRR 高于混合模式，不能宣称 RRF 对每类查询都更好。

例如“请查找题号 V1-TIME-DURATION-002 的题目”，Dense 前五名未命中，BM25 和混合模式均排第 1。另一个题号 `V1-RECTANGLE-AREA-002` 在 Dense 前五名未命中，BM25 排第 2，混合模式排第 3。保留这种差异，避免只展示融合成功的个例。

题号存在于结构化练习标题中，没有进入旧 Dense 的题干编码。新增关键词分支索引了这些标题，所以本次收益同时来自新增可搜索字段，不能全部归因于 RRF 公式。知识点标签也只代表主题相关，不代表某一片段足够解答问题，更不等于生成答案正确率。

本次数据是少量近源开发样例，没有独立保留集、复杂多跳或真实用户问题。自然问题的指标已经接近上限，需要更丰富的语料和独立评测集才能判断后续收益。参数在运行前固定，没有根据这组结果调参。

## 验证与运行边界

- 54 项自动测试通过，覆盖中文及题号词项、BM25 公式、答案解析不参与词项排名、RRF 公式与去重、候选截断、稳定排序、模式参数和范围传递；原清洗、切分及问答引用测试继续通过。
- 对全部 39 个问题，Dense 模式 Top-5 与原 V2 的独立数据库距离排序 SQL 一致。
- 对融合结果重新计算 RRF，校验引用编号在最终顺序后分配，且所有结果符合课程范围。
- 年级冲突、学期冲突、教材冲突、暂无资料的年级及不存在的课程，在三种模式下均返回空结果，`ask` 不调用语言模型。
- BM25 词项零重合返回空结果；超过范围内语料上限明确报错。默认上限 5000，已测试上限处理；没有进行 5000 片段负载压测。
- 新 `/api/v3/search` 默认混合模式；旧地址可显式指定 Dense 或 BM25。
- 实际浏览器已验证三种模式切换、分支候选展开、分数空值显示，以及无课程范围下两个操作按钮禁用；本机验收截屏为 `.runtime/v3-hybrid-search.png`（运行附件，不纳入 Git）。
- 本次评测调用 DeepSeek **0 次**，未验证新检索模式下的生成答案正确率；既有引用约束继续通过模拟响应测试。

上表耗时是已预热 CPU 上每题每模式执行一次的 `search()` 函数计时，复用只读事务连接，包含数据库网络耗时；不含 HTTP 传输、JSON 编解码和模型预热，不代表新建连接、冷启动或并发性能。每题轮换模式执行顺序，问题向量没有缓存。BM25 模式不执行神经网络推理，不能把它更快解释为系统整体加速。

本次升级不增加表、不改变 RLS、不重新生成库内向量。对照数据保存在项目的 `data/v3/` 中；历史 V1、V2 文件未覆盖。浏览器可在“资料问答”选择模式，用“仅检索”查看两路候选与最终结果。
